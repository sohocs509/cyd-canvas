# Security policy

Please report vulnerabilities privately through GitHub's
**"Report a vulnerability"** button (Security tab of this repository), not in a public issue.

Include the firmware version, board, and steps to reproduce. You can expect an
acknowledgement within 7 days. Only the latest release is supported while the
project is pre-1.0.

Design rules the project holds itself to: HTTPS only, keyed API access, no default
credentials, no secrets in firmware images or the repository.
