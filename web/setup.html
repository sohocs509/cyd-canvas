Set up your display's Wi-Fi

Works with any cyd-canvas display in setup mode, using the Improv Wi-Fi Bluetooth standard. Needs Chrome on Android, Windows, macOS or ChromeOS.

  1. On the display, open the menu, then Wi-Fi setup (Bluetooth) (a new display is already in setup).
  2. Press Find my display and choose it in the list.
  3. When asked, tap ALLOW on the display itself.
